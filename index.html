    How a launch flows

    The default Ammora path, end to end. Each stage is a separate on-chain step with its own receipt — nothing is bundled or hidden.

    1. 01
      Create the Config

      The launchpad owner creates one reusable Config from a reviewed template, setting recipients and the Creator/Partner fee split.

      launch:team-config
    2. 02
      Issue the token

      A Creator calls createLaunch — a new token plus its pre-graduation ALC bonding curve are created together. An atomic variant creates Config, token and first buy in one flow.

      launch:create-launch
    3. 03
      Trade on the ALC curve

      Anyone can buy and sell against the curve before graduation. Quotes are read first, then swapped through the curve (model dbc).

      launch:quote → quickstart:swap
    4. 04
      Graduate

      When the curve fills, a final buy reconciles the consumed input and the launch reaches ReadyToMigrate; a separate migration transaction performs graduation.

      launch:graduate
    5. 05
      Trade the ARL pool & claim fees

      Migration creates the post-graduation concentrated ARL pool and the Config-defined LP positions. Creator and Partner claim FeeVault fees separately; the LP NFT owner claims position fees.

      launch:claim-fees · arl:claim-position-fee
